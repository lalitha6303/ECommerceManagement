# E-Commerce Shopping and Order Management System

## Project Overview

The **E-Commerce Shopping and Order Management System** is a Core Java project developed to simulate the basic operations of an online shopping platform. It manages customers, products, shopping carts, orders, payments, subscriptions, and discount offers using object-oriented programming principles.

The project is designed with separate modules to improve code organization, maintainability, and reusability.

## Features

### 1. Customer Management
- Add and manage customer details.
- View and search customer records.
- Update and delete customer information.
- Apply encapsulation to protect customer data.

### 2. Product Management
- Add, view, search, update, and delete products.
- Manage product prices and available stock.
- Update product quantities when stock changes.

### 3. Shopping Cart Management
- Add products to a customer's cart.
- Manage product quantities in the cart.
- View cart items and clear the cart.

### 4. Order Management
- Place orders using items in the shopping cart.
- Validate product availability before placing an order.
- Calculate order totals and shipping costs.
- Update product stock after a successful order.
- Clear the cart after placing an order.

### 5. Payment Management
- Simulate payment processing.
- Maintain payment records.
- Support payment-related operations, including refunds.

### 6. Subscription Management
- Manage customer subscriptions.
- Check subscription status.
- Apply free shipping for customers with active subscriptions.

### 7. Discount Management
- Create and manage discount offers.
- View and delete discounts.
- Activate or deactivate discounts.
- Calculate discounts based on the configured discount type.

## How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Ensure a compatible JDK is configured.
4. Open `src/Main.java`.
5. Run the `main()` method.
6. Follow the console menu to access the available management operations.
